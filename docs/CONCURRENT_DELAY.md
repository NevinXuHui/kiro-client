# 并发注册延时配置说明

## 功能说明

在并发注册时，每个账号之间可以配置延时时间，避免同时发起大量请求触发风控。

## 工作原理

### 串行模式（并发数 = 1）

```
账号1 注册 → 延时 → 账号2 注册 → 延时 → 账号3 注册
```

每个账号注册**完成后**延时，然后开始下一个。

### 并发模式（并发数 > 1）

```
时间 0s:   启动账号1
           ↓
时间 3s:   启动账号2 (延时3秒)
           ↓
时间 6s:   启动账号3 (延时3秒)
           ↓
...

并发执行：
账号1: ████████████████ (15秒)
账号2:    ████████████████ (15秒)
账号3:       ████████████████ (15秒)
```

每个账号**启动前**延时，控制任务启动频率，避免瞬间并发过高。

## 使用示例

### GUI 界面

在注册机页面配置：
- 数量: 10
- 并发: 3
- 延时: 5 (秒)

### API 调用

```go
import "reg_go/internal/task"

req := task.StartTaskRequest{
    Count:       10,    // 注册10个账号
    Concurrency: 3,     // 并发3个
    Delay:       5,     // 每个账号启动间隔5秒
    EmailProvider: "cloudmail",
    // ...
}

result := task.StartTask(req)
```

### 命令行（未来 TUI）

```bash
kiro-cli register \
  --count 10 \
  --concurrency 3 \
  --delay 5 \
  --email-provider cloudmail
```

## 最佳实践

### 推荐配置

| 场景 | 数量 | 并发 | 延时 | 说明 |
|------|------|------|------|------|
| 测试 | 1-2 | 1 | 0 | 快速测试 |
| 少量注册 | 3-5 | 1-2 | 3-5 | 稳定优先 |
| 批量注册 | 10-20 | 3-5 | 5-10 | 平衡速度和风控 |
| 大量注册 | 50+ | 5-10 | 10-15 | 避免触发风控 |

### 注意事项

1. **并发不是越高越好**
   - 并发过高容易触发 AWS 风控
   - 建议不超过 10 个并发

2. **延时很重要**
   - 延时为 0 时，瞬间启动大量任务
   - 建议至少 3-5 秒延时
   - 使用代理池时可以适当减少延时

3. **观察日志**
   - 如果频繁出现 "被拦截" 或 "429 限流"
   - 增加延时或减少并发

4. **使用代理池**
   - 配置代理池后，每个账号使用不同代理
   - 可以适当增加并发或减少延时
   - 但仍建议保持延时避免瞬时冲击

## 计算总时间

### 串行模式

```
总时间 = (单个注册时间 + 延时) × 数量
例: (15秒 + 5秒) × 10 = 200秒 ≈ 3.3分钟
```

### 并发模式

```
总时间 ≈ MAX(
  单个注册时间 × CEIL(数量/并发),
  延时 × (数量-1)
)

例1: 并发3，延时5秒，10个账号
  ≈ MAX(15秒 × 4, 5秒 × 9) = MAX(60秒, 45秒) = 60秒

例2: 并发5，延时10秒，20个账号
  ≈ MAX(15秒 × 4, 10秒 × 19) = MAX(60秒, 190秒) = 190秒
```

实际时间取决于：
- 网络延迟
- 代理速度
- AWS 响应时间
- 邮箱接收验证码速度

## 故障排查

### 问题 1: 延时不生效

**现象**: 所有账号同时开始注册

**原因**: 旧版本不支持并发延时

**解决**: 
```bash
git pull
go build -o kiro-client .
```

### 问题 2: 延时过长

**现象**: 任务执行时间远超预期

**排查**:
1. 检查延时配置是否过大
2. 查看日志中的实际延时值
3. 调整延时参数

### 问题 3: 仍被风控

**现象**: 即使配置延时仍然被拦截

**可能原因**:
- 使用相同的 IP/代理
- 邮箱域名被拉黑
- 浏览器指纹被识别

**解决**:
- 配置代理池
- 更换邮箱域名
- 增加延时到 10-15 秒
- 减少并发数到 2-3
